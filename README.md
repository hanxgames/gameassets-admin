# gameassets.tr yönetim paneli

Statik panel: GitHub REST API ve ince ayarlı erişim anahtarı (yalnızca hanxgames/gameassets.tr, Actions ve Contents okuma/yazma) ile çalışır. Anahtar yalnızca tarayıcıda saklanır; bu repoda gizli bilgi yoktur.

- itch.io senkronunu tetikler ve canlı izler
- Siteyi yeniden yayınlar
- Paketleri sitede gizler/gösterir (src/data/hidden.json)
- Son yayınları ve çeviri durumunu gösterir
